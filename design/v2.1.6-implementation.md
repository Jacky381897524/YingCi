# V2.1.6 implementation notes

## Material and geometry

- Circle intent is explicit in GlassItem, mapped to upstream shape type 2. All round icon controls have equal 48dp sides; attachment remove controls retain a 44dp touch target around a 23dp circle. Slider/switch thumbs are also analytic circles.
- Chat material kind 7 uses frost 1 and 32dp backdrop blur with theme-dependent translucent tint. Neither TextField nor AI bubbles draw an opaque foreground fill.
- Bubble outlines are cached alpha masks (maximum 1024x2048), uploaded alongside the existing backdrop textures. Masks are released from the GL cache after leaving the scene. The upstream shader remains verbatim; GlassOverlayShader adds mask and per-pixel fade at compilation.
- The native fallback is translucent but cannot reproduce GPU refraction. It uses the same outline and is suitable for layout regression tests, not GPU appearance claims.

## Scrolling

HeaderOverlay layers fixed controls above full-height scrolling viewports. Insets are measured from the actual header (including open search). Initial content starts below the header; scrolled content travels behind it. Native alpha and GL alpha use smoothstep from zero at the viewport top to full opacity at the header bottom. The system status inset remains reserved.

Reverse mode must be eagerly read in the parent composable to resubscribe to the correct in-memory image/result flows when header and content have separate composition scopes.

## Skill

Source: https://github.com/shengjidaguai-china/goutoujunshi

Pinned commit: 6db7354a4002dc7c448a9c87ffdad8132570c9d3

Only SKILL.md, LICENSE and textual references are bundled. The 43 reference files are losslessly packed into an ASCII-path JSON asset for compatibility with Windows-hosted resource tests. `scripts/vendor-goutou-skill.cjs` rebuilds this asset from `.tools/vendor/goutoujunshi` without executing any upstream scripts.

Conversation JSON gains an optional skill field; absent/unknown values default to normal chat. Selection persists locally. The prompt adapter sends the core skill plus at most three references, prioritizes risk topics, and retains the existing JSON chat/image-proposal protocol. No implicit image generation, model change, credentials change or external storage occurs.

Not implemented: upstream shell/file tools, ChatLab integration, cross-conversation relationship profiles, live web research. The adapter explicitly informs the model that these are unavailable.

## Removed feature

The global theme/wallpaper page, routes and ViewModel setters are removed. Legacy preference fields remain readable for backward compatibility, but global wallpapers are not rendered. Existing files are not deleted. Separate chat wallpapers and the three appearance modes remain.
