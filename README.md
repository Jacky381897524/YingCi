## 功能

- 本机提示词收藏：封面和名称双列展示、名称及两版正文模糊搜索、编辑名称/封面/正文、一键复制。
- 原始版本不可覆盖，反复编辑仅替换当前修改版。反推结果在首次收藏前被编辑时，也保留模型的原始输出。
- 风格反推提取可迁移的画风、光影、材质、版式规则；正常反推描述主体和画面细节，配合原图进行接近原图的生成。两种模式分别保留本次使用中的图片、结果和编辑草稿；切换不调用模型，进程结束后临时内容清空。
- 跟随系统/浅色/深色，五档全局字号与文字预览。全局主题预设和逐页壁纸功能已移除，旧壁纸文件不再应用但不主动删除。聊天菜单仍可设置聊天背景。
- 顶栏搜索、四个纯图标导航；收藏标题位于封面内部底部居中，13sp白色中等字重配轻阴影，新标题最多30个Unicode字符、单行。超出显示宽度时省略，旧长名称原文保留。长按封面提供编辑、红色删除图标，删除需再次确认。
- 第三页首先显示最近对话，支持查找标题和正文；进入对话隐藏导航栏，返回恢复列表。聊天默认共用识图模型，可在设置中配置独立聊天地址、加密密钥和模型并读取列表。
- AI 判断聊天/识图/生图意图，只生成待确认方案。点击确认后才能提交生图，可修改提示词、参考图、比例、质量、张数及分别生成。后续图片修改传递最近相关图片与对话。每次模型请求最多24条相关消息、6张图片和约6万字符，避免无限膨胀；长对话不会全部发送。
- 对话消息、附件、生成图片在本机保存；旧生成记录迁移到最近列表。删除/清空对话同步清理关联图片，独立收藏封面和手动导出的相册图片不受影响。待处理生成任务须先停止。
- 用户气泡浅色蓝/深色黄，AI气泡及输入框使用透背景的磨砂玻璃；同一方连续消息仅末条带尾巴。聊天背景在各对话间共用。顶部内容在固定标题后方平滑渐隐，原生内容和GL图像使用同一曲线，固定按钮不渐隐。
- 聊天菜单的“狗头军师”可启用或退出，状态随当前对话保存；普通新对话默认不启用。内置原始技能和43份参考，每次按主题选1至3份，额外提示有长度上限；不执行仓库脚本、不读取其他应用、不支持跨对话关系档案写入。
- Liquid Glass 原仓库 V2 核心着色器及17项参数保持；文字玻璃使用最大磨砂和较高模糊，纯图标强制清透，其余材质参数仍可调整。
- ZIP 导出和合并恢复；备份保留封面及两版提示词，不含密钥。

## 模型配置

填写 HTTPS 服务地址（例如服务商提供的 `/v1` 地址）、API Key、识图模型名和生图模型名。这里的示例地址不是可用服务，必须填写自己的真实配置。

识图使用 OpenAI Chat Completions 图片输入或 Claude Messages 接口；Gemini 使用官方 OpenAI 兼容接口。生图连接测试仍使用 Images Generations 接口，不因聊天适配而自动支持所有平台的原生生图协议。识图与生图共用原设置中的地址和密钥，聊天可独立配置。只使用反推时可以不填写生图模型。

识图测试发送随机纯色测试图片，并检查模型是否识别出正确颜色。生图测试经确认后实际生成一张测试图并校验图片内容，可能产生服务商费用，不会添加到收藏。反推也会发送所选图片到填写的服务商。没有自建服务器，收藏功能可离线使用，AI 功能需要联网。

API Key 使用 Android Keystore 加密保存在本机，独立聊天密钥同样加密。测试包不含任何真实密钥。聊天只要求文字能力，图片识别另行测试；读取模型列表并不保证权限、渠道或模型能力已通过验证。反推相似度由识图和生图模型决定，不能保证完全一致。

### 生图适配

- Agnes 官方域名上的 Image 2.1/2.5 Flash 使用 `extra_body.image` 传参考图；开放比例、1K/2K/3K/4K 和返回格式。
- `gpt-image-1` 参考图使用 `/images/edits` 多部分表单；无图使用 `/images/generations`。
- `dall-e-3` 为文生图；其他兼容模型仅发送基础文生图字段，不擅自忽略参考图。接入商必须支持相应接口。
- 最多6张参考图，每组1至4张输出，每次网络请求只生成1张。多图分别生成时，张数按参考图数累加。
- 生成使用前台服务，后台完成后在允许通知时通知。系统强制停止或超时后不自动重发；已提交但结果未知的任务需核对服务商账单后手动重试。不能保证系统杀进程后取回结果。
- 所选参考图会整理为最长边2048像素的 WebP；生成结果原文件保存，单图上限32MB/4000万像素。相册只在手动保存时写入 `Pictures/映词`。

协议依据：[Agnes 2.5 Flash](https://agnes-ai.com/en/docs/agnes-image-25-flash)、[Agnes 2.1 Flash](https://agnes-ai.com/en/docs/agnes-image-21-flash)、[New API 图像接口](https://doc.newapi.pro/api/openai-image/)。

V1.0.0 修订构建 2 增加连接错误详情：显示 HTTP 状态、服务商的 JSON 错误原因及请求编号，支持长按选择复制；限制错误响应长度并遮盖配置密钥。不将 HTML 网关页面直接展示为错误详情。此改动改善诊断，不代表服务商的 503 已解决，也不改变模型请求格式。

`https://apihub.agnes-ai.com/v1` 会被正确拼接为 `/v1/chat/completions` 或 `/v1/images/generations`，不会重复 `/v1`。公开接口的无密钥可达性检查不能证明某个账户或模型可用，仍需要在手机上使用实际配置测试。

协议参考：[Chat Completions](https://developers.openai.com/api/reference/resources/chat)、[Images](https://developers.openai.com/api/reference/resources/images)。

模型列表使用服务根路径下的 `GET /models`，OpenAI 兼容服务使用 Bearer 密钥认证，Claude 使用 x-api-key 与版本头；只读取名称，不发起生成请求，失败时仍可手动填写。参考：[New API 模型列表协议](https://docs.newapi.pro/zh/docs/api/ai-model/models/list/listmodels)。

用户截图中的 Agnes 报错已明确：`Agnes-Image-2.5 Flash` 被服务商判定为生图模型，不能充当反推所需的识图文字模型；其生图请求又被服务商以当前 `default (distributor)` 分组无可用渠道拒绝。后者需核对服务端模型 ID、密钥分组、权限及渠道状态，客户端升级不能开通渠道。未使用用户真实密钥完成在线生成验证。

## 数据目录

所有日常数据在应用专属目录内，不散落到公共相册：

```text
databases/yingci.db       提示词、两版正文、封面索引
databases/generations.db  生成任务、结果和状态索引
databases/conversations.db 对话与消息索引
files/covers/<id>/        归档封面
files/generations/<id>/   每条任务的参考图副本、生成原图
files/conversations/<id>/ 每段对话的上传图片副本
files/wallpapers/         当前自定义壁纸及内置湖景
cache/drafts/             临时导入图片，过期清理
cache/restore-<id>/       恢复暂存，完成后清理
shared_prefs/             外观配置及加密后的密钥
```

封面导入时按最长边 2048 像素整理；列表按较小尺寸异步解码，内存图片缓存限制为 32 MB。仅用户主动导出时向选定位置写入备份。现有 ZIP 备份仅包含收藏和封面，不含聊天/生图历史、壁纸或密钥。卸载或清除应用数据会删除本机数据，请先备份收藏并将所需生图导出到相册。

## 构建和测试

`scripts/build-android.ps1` 优先使用当前项目 `.tools` 中的 JDK 17、Gradle 8.11.1、Android SDK 35 和依赖缓存，可通过 `-BuildToolsPath` 指定工具目录；本地工具不可用时回退到相邻 `Huitu skill/.tools`。当前项目的 `.tools/yingci-test.keystore` 为稳定的本机测试签名，应保留以供后续覆盖升级。

默认执行发布构建、单元及界面测试、Android Lint，然后验证 APK 签名和 16 KB 对齐。测试截图位于 `.tools/test-home/qa`，测试报告位于 `android/app/build/reports/tests`。`scripts/check-reference-material.cjs` 检查原仓库着色器一致性、WebGL 编译及参数产生的像素变化。

应用包名 `cn.yingci.local`，与相邻旧项目的 `cn.yingci.app` 独立安装，避免覆盖旧应用资料。

## 视觉与测试边界

已批准的两张设计稿在 `design/03-v2-liquid-library.png` 和 `design/04-v2-liquid-settings.png`。界面使用 Android 可用的无衬线系统字体，按 iOS 风格调整字号、字重和间距，不包含 Apple 专用字体。

原生宿主提供布局、纹理和手势，核心玻璃 shader 保留源文件。不能仅凭 shader 一致就宣称整个应用和网页逐像素相同。Robolectric 测试不代表 vivo 真机 GPU、触屏或持续高刷性能；无设备连接时不宣称已完成真机验收。真实服务连接需要使用者填写有效配置后验证。
