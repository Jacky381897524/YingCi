# V1.0.2 四页交互预览

入口：`YingCi-preview.html`，已内嵌脚本、图片和字体之外的全部资源。字体使用设备系统字体。无需服务器；建议用 Chrome 或 Edge 打开。此文件只使用开源仓库内的示例图片，不包含真实 API Key 或手机收藏。

新增入口：`YingCi-generation-preview.html`，直接打开生图页，其余内容与主入口相同。此次只补设计预览，用户确认生图界面后才进入正式 Android 实现。不是 V1.0.2 APK。

## 范围

- 收藏、风格反推、生图、设置四页切换。
- 收藏顶栏搜索展开和收起，筛选示例收藏；搜索不增加顶栏高度。
- 收藏标题位于封面内部下方的玻璃胶囊中，最多两行，字号适配。新建示例标题最多16个字符。
- 前景图标/按钮文字与玻璃使用同一套屏幕坐标；按压缩放，不跟随手指平移。通过玻璃按钮拖动时转发列表滚动。
- 图片、文字以及设置图标进入背景纹理。使用原仓库 V2 片段着色器，浏览器端使用 sRGB 纹理和自动 mipmap。此实现不是原生 Android 渲染管线的直接替换。
- 设置中可切换浅色/深色/跟随系统和五档字号。浅色蓝色强调、深色黄色强调；玻璃文字浅色白字黑边、深色黑字白边。
- 显示页可以临时调整折射和厚度。主题壁纸、模型连接、备份本次只展示入口，不执行真实操作。
- 反推页使用明确标注的示例结果，可选择本机图片、复制示例文字；不会真正反推或调用模型。
- 本次示例状态只存于内存，关闭后消失。没有修改 Android 源码、签名或已交付 APK。

## 生图预览

- 按用户最新反馈合并成单一生图表单：不添加图片默认文生图，添加一张或多张自动参考，不设置模式切换。多图时才显示“分别生成”开关，默认关闭；移除至一张时重置，全部移除后自动回到文生图。
- 本机图片仅在浏览器内读取，不上传。预览最多6张，每张上限20MB，不等同于真实服务限制。
- 输入提示词、从收藏选择、从收藏详情或反推页带入提示词。比例、清晰度和张数为参数布局示意，真实支持情况尚未验证。
- 高级参数折叠，尚未检测模型能力时不放置无效滑块。未读取手机模型设置，也未连接真实接口。
- “预览生成结果”只展示内置示例图，不执行AI生图，不假装具有真实生成进度。所选比例与清晰度不改变示例图，结果页已明确说明。
- 结果页完整查看图片、导出示例图、复制提示词、恢复参数。右上角菜单支持设为已有收藏封面、新增收藏、删除。
- 更换封面、删除需确认；生成记录支持单选、多选、清空。新收藏拥有独立记录，删除历史后仍保留封面和提示词。此处只是数据模型验证，不是Android文件清理的验证。
- 弹出菜单含焦点约束、Escape关闭、背景禁用。新收藏名称按Unicode字符计数，最多16字；超长粘贴拒绝、不默默截断。
- 生成任务后台运行、通知、真实API请求、持久存储、文件释放及升级迁移属于后续APK实现，不在此预览中。
